## Selected Projects

### BloomLink — URL Shortener with Bloom Filter Optimization
- Built a URL shortener using FastAPI with a focus on reducing unnecessary database access  
- Integrated Bloom Filters for constant-time membership checks before hitting the database  
- Used Redis for caching and PostgreSQL for persistence, containerized with Docker  
- Designed to handle high read traffic efficiently by minimizing redundant queries  

---

### VoicePay — Voice-Based Payment System
- Developed a payment system that verifies transactions using voice input  
- Applied ML-based confidence scoring and intent validation for authentication  
- Built full-stack flow using React and Flask with a focus on secure transaction handling  

---

### LearnHive — Tutoring Marketplace Platform
- Designed a multi-role system for students and tutors with scheduling and booking workflows  
- Built backend using TypeScript, Node.js, and Prisma ORM  
- Modeled relational data and handled real-world constraints in PostgreSQL  

---

### C++ Compiler Front-End
- Implemented a lexical analyzer and recursive descent parser from scratch  
- Generated Abstract Syntax Trees (AST) and performed semantic checks  
- Focused on correctness, parsing logic, and memory-level understanding  

---

### DeadlockMaster — OS Deadlock Simulator
- Simulated resource allocation and deadlock scenarios in operating systems  
- Implemented cycle detection and recovery strategies  
- Built to understand system-level behavior rather than just theory
